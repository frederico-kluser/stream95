# Storybook map — React95 (`packages/core/stories/*.stories.tsx`)

Live: <https://react95.github.io/React95/> (index fetched 2026-10-27: 85 entries, matching
the repo at `97bd045`). Open a story with `?path=/story/<id>`, its docs page with
`?path=/docs/<title-id>--docs`, or the bare canvas with `iframe.html?id=<id>&viewMode=story`.
Stories import from `../components/...`; in an app import the same names from
`@react95/core` (or its subpaths).

## Global setup (`packages/core/.storybook/`)

- `preview.js`: decorators `Frame` and `withClippy`; global `selectedTheme` (default
  `win95`); `storySort: { order: ['All'] }`; a11y addon with `test: 'todo'`.
- `decorators/Frame.tsx`: imports GlobalStyle and applies the selected theme with
  `setElementVars(document.documentElement, contract, tokens[theme])` (the runtime
  theme-switching recipe), and pads every story by 10px.
- `src/theme-changer` addon: a "Themes" panel of mini windows, each styled with
  `assignInlineVars(contract, tokens[name])`; clicking one updates the global theme.
- `decorators/withClippy.tsx`: one `ClippyProvider` (random agent) mounted in its own React
  root; stories may set `parameters.clippy.phrases` and receive `speak(text)` in the render
  context (`render: (_, { speak }) => …`).
- `parameters.design`: Figma frames of the "React95 Design Kit"
  (`https://www.figma.com/design/2cbigNitjcruBDZT12ixIq/React95-Design-Kit`).
- Tests: every story is a Vitest browser test (Playwright/Chromium) unless tagged `!test`;
  `play` functions assert behavior — they are the best executable spec of each component.

## The `All` showcase (`all--all`, `all.stories.tsx`)

`composeStories` renders other stories **with their args** inside a
`div { display: flex; flex-direction: column; flex-wrap: wrap; height: 620px }` (children get
`margin-right: 10px`), in this order:

1. "Show Alert" `Button` + an `Alert` that starts open ("Windows Networking", type `error`,
   `dragOptions.defaultPosition {130,130}`, `TitleBar.Close` and OK both close it).
2. `button--simple` · 3. `avatar--simple` · 4. `checkbox--all` · 5. `dropdown--simple` ·
3. `fieldset--simple` · 7. `input--simple` · 8. `titlebar--simple`, `titlebar--inactive`,
   `titlebar--complete` · 9. `textarea--simple` · 10. `tree--simple` · 11. `range--simple` ·
4. `radiobutton--simple` · 13. `tooltip--simple` · 14. `list--with-icons` + `list--simple` ·
5. `progressbar--simple` · 16. `tabs-tab--simple` (inside a 400px-high box) ·
6. `video--from-url`.

Not in the showcase: Modal, TaskBar, useModal, Frame, Cursor, GlobalStyle, Contract, Icon.
Tagged `!test`, controls/interactions disabled.

## Finding the right example fast

| Need                             | Story                                                       |
| -------------------------------- | ----------------------------------------------------------- |
| Window with menu, buttons, close | `modal--simple`                                             |
| Windows + taskbar + minimize     | `modal--minimize`, `modal--multiple`, `taskbar--simple`     |
| Programmatic window control      | `hooks-usemodal--*`                                         |
| Start menu / context menu        | `list--with-icons`, `list--simple`                          |
| Properties dialog with tabs      | `tabs-tab--simple`                                          |
| File explorer tree               | `tree--simple`                                              |
| Message box                      | `alert--*`                                                  |
| Layout primitives & tokens       | `frame--*`, `contract--theme`, `contract--code-examples`    |
| Custom/scoped theme              | `contract--custom-theme` (mind the baseTheme import caveat) |
| Fonts, scrollbars, setup         | `globalstyle--*`                                            |
| Find an icon name                | `icon--all`                                                 |
| Cursors                          | `cursor--simple`                                            |
